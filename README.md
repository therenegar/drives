## Purpose

It's the tiniest of utilities but it's super helpful...what drives exist in your DOS environment?
Where did my CD-ROM drive get mounted to? 
Did the network drive get connected?

Answer all these questions and more!

Includes floppy disk, hard disk, RAM disk, CD-ROM and network drives.

## Requirements

* 8086 or later processor
* DOS 3.x or later 

## Install

Just download [DRIVES.EXE](https://github.com/therenegar/drives/blob/main/DRIVES.EXE) directly and place anywhere you like.


## Syntax

At the command prompt, type `DRIVES` to see the available disk drives.
